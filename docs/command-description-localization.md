# 斜杠命令说明汉化

桌面壳会在受信任的 DSH 主页面加载后注入渲染观察器，将斜杠菜单中仍为英文的六条说明替换为中文：`compact`、`export`、`feedback`、`goal`、`permission` 和 `plan`。

观察器只处理 ID 以 `dsh-slash-option-command-` 开头的命令选项，并只匹配已确认的完整英文说明；命令目录请求、候选生成方法、命令名、执行参数、排序、选择行为和已经是中文的 `model` 说明保持不变。未命中的新命令或上游改写文案继续显示 Runtime 原文。

修改源码后需要重新构建并重启桌面壳。单独更新 DSH Runtime 不会包含本汉化注入；升级 Runtime 后应运行专项测试，并在实际会话输入 `/` 检查六条说明。
