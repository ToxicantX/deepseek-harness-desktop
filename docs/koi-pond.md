# 后院鱼塘

## 使用

主界面加载后，窗口菜单「帮助」右侧出现「后院鱼塘」。点击直接打开独立窗口；再次点击会唤回已有窗口，不会重复创建。该功能仅依赖桌面壳，不修改 DSH 核心、会话数据库或模型请求内容。

- 初始住客：丹枫、墨雪、小金、浅葱，包含红白、大正三色、黄金、秋翠四种花色，初始等级 1。
- **投喂**：点击池面投下五粒饲料，附近锦鲤主动转向追食。最多同时存在 45 粒，投喂间隔至少 250 毫秒，未吃完的饲料 25 秒后移除。投喂不增加等级。
- **抚水**：切换「抚水」后轻点水面，只产生涟漪，不投饲料。
- **键盘**：聚焦池面后用方向键调整落点，空格或回车执行当前互动。
- **档案**：点击右侧锦鲤查看性别、花色、代际、成熟进度，可保存 1–16 个字符的名字。
- **昼夜**：点击右上角「入夜／天明」切换氛围；该选择仅作用于当前窗口。
- 不设置饥饿、死亡、离线惩罚或付费内容。窗口隐藏时暂停动画，关掉鱼塘不停止对话成长。

## 成长与繁育

1. 主会话消息经 Runtime 的 `prompt` 返回 `ok: true` 后，当前所有锦鲤各升 1 级。这里统计的是**消息成功发送**，不是模型完成回答；新会话和已有主会话均适用。
2. 历史加载、助手回复、工具事件、子智能体消息、发送失败以及壳侧原会话编辑重试均不计数。正常聊天中另发一条消息仍会计数。
3. 每 100 级增大体型并舒展鳍尾，200 级开始显现鳞纹；1000 级达到视觉尺寸上限，此后等级继续记录陪伴。
4. 达到 500 级且尚未繁育的异性锦鲤自动配对，每对产 1 枚卵。初始四条鱼同时成熟时可以形成两对、得到两枚卵。
5. 新卵需要**之后的 5 次对话**孵化；小鱼初始 1 级，随机性别，继承父母之一的花色，代际为父母最高代际加 1。
6. 每条鱼一生繁育一次，鱼与卵合计上限 16，满池不继续产卵。投喂和改名不推进孵化。

## 存档与故障边界

- 存档位置：Electron `app.getPath('userData')` 下的 `koi-pond.json`，一般为 `%APPDATA%\deepseek-harness-desktop\koi-pond.json`。不读取聊天正文。
- 首次进入壳即创建初始存档，不要求先打开鱼塘。等级、名字、代际、鱼卵与最近 4096 个消息去重键持久化。
- 去重键由会话 ID 与消息请求 ID 组成；重复通知不重复成长。旧 Runtime 未传请求 ID 时生成本次本地通知 ID，因此不承诺跨刷新或网络重试识别同一消息。
- 存档更新先写同目录临时文件，再替换正式文件，写入成功后才提交内存状态。写入失败不占用消息去重键；存档损坏时保留原文件并显示错误，不擅自重置。
- 鱼塘错误记录到桌面日志，不改变聊天发送结果。磁盘故障期间的成长通知没有离线补偿队列，不能承诺恢复后自动补记。
- 备份或恢复存档前先正常退出桌面壳。恢复时用备份覆盖上述文件，再启动；不要在壳运行时编辑存档。
- 此功能观察壳当前页面的发送动作；其他客户端发送的消息、壳关闭期间的消息不补计。

## 实现与验证

页面资源全部本地加载，Canvas 程序绘制池水、卵石、荷叶与锦鲤，没有外部图片、字体、接口或新增依赖。窗口启用隔离和沙箱，不提供 Node 权限；仅允许自身主 frame 使用读取存档和改名 IPC。

对话观察与原会话重试共用壳侧模块工厂转换链，按注册顺序组合，不互相覆盖。匹配失败时保留原始聊天模块并写控制台警告；DSH 升级后应重新验证匹配，不将历史验证视为永久兼容。

在仓库根目录、Node 24 环境执行：

```powershell
pnpm test
pnpm run build
node scripts/smoke-koi-pond.mjs "$env:LOCALAPPDATA\DeepSeek Harness\runtime-manager\runtimes\0.1.3-alpha.1"
git diff --check
```

冒烟脚本只读指定 Runtime，验证原会话重试与成长观察组合后的工厂语法，并以模拟 API 执行当前 Runtime 的真实发送方法体。再启动独立隐藏 Electron 实例，使用临时存档、真实页面和构建后的 preload，检查投喂追食、涟漪、改名、昼夜、单窗口、去重、关闭窗口后成长、重开与存档恢复，以及 680×520 小窗口。

为确保隐藏窗口持续产生动画帧，脚本仅在临时转译的窗口副本中启用 offscreen 渲染；不改变产品窗口配置。结果和日／夜／小窗口截图保留在输出的临时目录。它不发送真实模型请求，不启动主壳、不操作正在运行的实例、不打安装包。

发布前还需在新构建的主壳中人工确认原生菜单位置、真实聊天触发成长，以及安装包内资源加载。当前运行中的旧壳不会自动加载本轮源码。

## 回滚

仅针对本功能的当前改动，保留已有主题设置修改、用户鱼塘存档与历史进度日志：

```powershell
git restore --source=HEAD -- src/main.ts src/preload.ts src/conversation-replay-injector.ts tsdown.config.ts
Remove-Item -LiteralPath assets/koi-pond.html, assets/koi-pond.css, assets/koi-pond.js, src/koi-pond-injector.ts, src/koi-pond-preload.ts, src/koi-pond-store.ts, src/koi-pond-window.ts, tests/koi-pond.spec.ts, scripts/smoke-koi-pond.mjs, docs/koi-pond.md
pnpm run build
```

以上命令适用于本功能尚未提交且这些四个已有源码文件没有新增其他修改的状态。提交或继续开发后，按本功能提交／补丁精确回退，勿覆盖后续工作。
