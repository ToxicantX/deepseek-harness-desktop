# 后院鱼塘

## 使用

水域按用户红框参考图的内侧轮廓描点，替代原中央椭圆：扩大顶部、左右及底部可游动区域，保留荷叶与岸边凹口。鱼的位置约束、游动目标、投食/玩水命中和折射裁切使用同一轮廓，并随背景等比缩放与裁切；红线本身不显示。边缘投食的随机散落不会落到轮廓外。鱼的位置约束以中心为准，鱼尾等绘制部分可能伸过边界。

主界面加载后，右下角显示「池」悬浮球，悬停可见「后院鱼塘」。点击后在当前主窗口中显示鱼塘，不再打开独立窗口或使用顶部菜单入口；鱼塘内仍使用同一个右下角悬浮球切回对话，不再显示单独返回按钮。底层聊天页面不会导航或销毁，因此原来的工作区、会话和输入草稿保留。该功能仅依赖桌面壳，不修改 DSH 核心、会话数据库或模型请求内容。

- 初始住客：丹枫、墨雪、小金、浅葱，包含红白、大正三色、黄金、秋翠四种花色，初始等级 1。
- **投喂**：点击中央可游动水域投下五粒饲料，附近锦鲤主动转向追食。岸边、屋顶等装饰区域不投食。最多同时存在 45 粒，投喂间隔至少 500 毫秒，未吃完的饲料 25 秒后移除。投喂不增加等级。
- **玩水**：切换「玩水」后轻点中央水面，产生向外传播、逐渐衰减的正弦折射波，不投饲料。效果直接扭曲水纹中的背景与锦鲤，并附带轻微波峰明暗，不再描画白色轮廓圈。连续点击的位移先叠加再采样，波纹在 2.5 秒动画时间内消失。投喂与进食也使用同一正弦折射效果，振幅为玩水的 45%，不再绘制旧椭圆描边，不增加力度设置项；系统启用减少动态效果时降低折射强度。
- **键盘**：聚焦池面后用方向键调整落点，空格或回车执行当前互动。
- **档案**：点击右侧锦鲤查看性别、花色、代际、成熟进度，可保存 1–16 个字符的名字。
- **性格**：初始四条锦鲤分别为好奇、胆小、贪吃、安静；后代根据自身标识稳定获得好奇、胆小、贪吃、安静、活泼或亲人性格。好奇锦鲤会靠近水域内的指针，胆小锦鲤遇到玩水会躲开，贪吃锦鲤追食更快，安静锦鲤巡游较慢，活泼锦鲤游动更快，亲人锦鲤在被选中后跟随指针。性格计算不修改原鱼塘存档结构。
- **亲密度**：范围 0–100。每次有效主会话对话让现有锦鲤各增加 1；每条鱼在一轮投喂中首次吃到饲料增加 2；选中的锦鲤在点击附近玩水增加 1，同一条鱼的陪玩奖励间隔至少 20 秒。亲密度会给游速带来最多 10% 的轻微提升，档案显示「初次相识／初生好感／渐渐熟悉／十分亲近／形影相随」阶段，不设降低或离线惩罚。
- **关系记录**：亲密度与最后同步的对话数保存在鱼塘专用持久化浏览器分区的 `localStorage`，与等级、繁育和鱼名存档分离。窗口关闭期间发生的有效对话会在下次打开时补记亲密度；本地关系记录损坏时从空记录开始，不影响主鱼塘存档与聊天。
- **对话庭院事件**：鱼塘窗口打开时，每次有效对话按对话序号产生约 42% 的稳定伪随机机会，最多同时展示一个事件，不排队。清晨和日间可出现花瓣、蜻蜓、青蛙或锦鲤跃水；傍晚和夜间将蜻蜓替换为萤火虫。花瓣持续 8 秒、蜻蜓 6 秒、青蛙 9 秒、萤火虫 8 秒、跃水 2.4 秒；事件仅改变当前画面，不增加等级、亲密度或存档字段。关闭窗口期间不播放也不补播视觉事件。
- **节气庭院**：按电脑本地日期自动切换季节，不依赖网络或定位。3–5 月为春季，6–8 月为夏季，9–11 月为秋季，12–2 月为冬季；春季增加粉色花瓣，夏季在傍晚和夜间增加流萤，秋季飘落红叶，冬季叠加薄雾。季节标签显示在底部铭牌，时段下拉仍只控制昼夜光照，不会覆盖本地日期季节。
- **事件表现**：花瓣缓慢旋转落入池面；蜻蜓每次随机选择方向、高度和曲线路径，飞行中持续振翅与侧倾；荷叶青蛙随水轻摆并随机时机小跳，落点带起浅水圈；每只萤火虫拥有独立速度、弧度、升降和方向，沿不同平滑曲线随机飞舞，同时保留暖光明灭；跃水锦鲤短暂离开水面并带起立体环形水花。五类事件均使用本地透明美术素材；禅模式保留事件画面但隐藏文字提示。
- **时段**：右上角下拉框可选择「自动时段」或「手动 · 清晨／日间／傍晚／夜间」，选择后立即生效，并在本机保存，重开鱼塘继续使用。默认自动：05:00–08:00 清晨、08:00–17:00 日间、17:00–19:00 傍晚、19:00–次日 05:00 夜间（起点包含、终点不包含），使用电脑本地时间，无需联网或定位。自动模式每秒校对，恢复显示或获得焦点时立即校对；手动模式固定所选时段，不受系统时钟变化影响，光照位置采用对应时段的代表时刻。切回自动立即恢复当前真实时段。设置保存失败时当次选择仍生效，并显示提示。
- **日光**：清晨采用柔和晨光调色，傍晚采用暖金与暮色调色，两者基于现有日间美术；夜间继续使用独立夜景。非夜间增加沿时间移动的柔光束与柔化叶影，限制在水域内，参与水波折射。光影纹理按分钟缓存，帧间仅轻微明暗变化；减少动态效果时保持静态亮度。这是轻量二维美术效果，不是按地理位置计算的真实太阳或三维阴影模拟。
- **禅模式**：点击右上角「禅」按钮隐藏池塘内的文字、面板、按钮及选中标记，保留池塘画面和右下角悬浮球；左键互动与对话成长继续生效，提示消息保持隐藏。单击鼠标右键退出并恢复原界面，不会误投饲料或弹出右键菜单。同一次运行中切换对话后保留禅模式，重启桌面壳后回到普通界面。
- **返回**：点击右下角悬浮球或按 Escape 收起鱼塘，回到原来的工作界面，不退出桌面壳。
- **执行列表**：左侧透明面板仅显示当前仍在执行的会话。多个会话并行发送时分别列出短会话标识和「执行中」状态；全部完成后面板自动隐藏。不显示消息正文、Token 或敏感配置。
- 不设置饥饿、死亡、离线惩罚或付费内容。窗口隐藏时暂停动画，关掉鱼塘不停止对话成长。

## 成长与繁育

1. 主会话消息经 Runtime 的 `prompt` 返回 `ok: true` 后，当前所有锦鲤各升 1 级。这里统计的是**消息成功发送**，不是模型完成回答；新会话和已有主会话均适用。
2. 历史加载、助手回复、工具事件、子智能体消息、发送失败以及壳侧原会话编辑重试均不计数。正常聊天中另发一条消息仍会计数。
3. 每 100 级增大体型并舒展鳍尾，200 级开始显现鳞纹；1000 级达到视觉尺寸上限，此后等级继续记录陪伴。
4. 达到 500 级且尚未繁育的异性锦鲤自动配对，每对产 1 枚卵。初始四条鱼同时成熟时可以形成两对、得到两枚卵。
5. 新卵需要**之后的 5 次对话**孵化；小鱼初始 1 级，随机性别，继承父母之一的花色，代际为父母最高代际加 1。
6. 每条鱼一生繁育一次，鱼与卵合计上限 16，满池不继续产卵。投喂和改名不推进孵化。

## 存档与故障边界

- 存档位置：Electron `app.getPath('userData')` 下的 `koi-pond.json`，一般为 `%APPDATA%\deepseek-harness-desktop\koi-pond.json`。不读取聊天正文。
- 首次进入壳即创建初始存档，不要求先打开鱼塘。等级、名字、代际、鱼卵与最近 4096 个消息去重键持久化。
- 去重键由会话 ID 与消息请求 ID 组成；重复通知不重复成长。旧 Runtime 未传请求 ID 时生成本次本地通知 ID，因此不承诺跨刷新或网络重试识别同一消息。
- 存档更新先写同目录临时文件，再替换正式文件，写入成功后才提交内存状态。写入失败不占用消息去重键；存档损坏时保留原文件并显示错误，不擅自重置。
- 鱼塘错误记录到桌面日志，不改变聊天发送结果。磁盘故障期间的成长通知没有离线补偿队列，不能承诺恢复后自动补记。
- 备份或恢复存档前先正常退出桌面壳。恢复时用备份覆盖上述文件，再启动；不要在壳运行时编辑存档。
- 此功能观察壳当前页面的发送动作；其他客户端发送的消息、壳关闭期间的消息不补计。

## 实现与验证

页面资源全部本地加载，运行时不访问网络。日／夜背景使用用户提供的两张设计稿，经本地像素处理清除固定 UI，再以 WebP 保存；可交互的文字、按钮、边框及荷花装饰由 HTML/CSS/SVG 重建，锦鲤、涟漪、饲料、节气素材与夜间微光由 Canvas 合成。窗口启用隔离和沙箱，不提供 Node 权限；仅允许自身主 frame 使用读取存档和改名 IPC。

### 氛围与界面美术

- 全场景增加静态暗角、中心通透层和极淡颗粒，拉开前景树荫、池面和岸边层次；这些效果使用 CSS 渐变，不创建逐帧纹理。
- 水域氛围使用独立缓存 Canvas：日间/清晨绘制细碎水光与少量漂浮花瓣，傍晚和夜间绘制暖色微光，清晨和夜间增加低对比薄雾。普通模式最多 18 个氛围点、每 100 毫秒重绘一次；系统启用减少动态效果时降为 8 个点并只绘制一次。主动画每帧只合成已缓存画布。
- 对话事件同一时间只保留一个；花瓣最多 12 片、萤火虫最多 10 只，减少动态效果时均降为 6 个并把飞行幅度压至约三分之一。每个实例只计算少量正弦曲线、缩放、旋转并合成一张已解码图片；蜻蜓、青蛙与跃水保持单实例，不建立图片序列、持续增长的粒子队列或新增逐像素处理。
- 锦鲤增加低透明尾流、身体金边、背部柔光和原有等级鳞纹，仍使用每条鱼固定数量的 Canvas 路径，不增加粒子数组、图片序列或逐像素处理。
- 侧栏、工具条和提示条使用 `assets/koi-pond-washi.webp` 的深墨绿和纸纤维材质，叠加细金线、内高光和选中光标；底部增加当前时段与时钟铭牌。纹理为 512×512、约 20 KB WebP，仅作为低对比 UI 材质，不覆盖庭院背景。
- 和纸纹理使用 GPT Image Proxy 的 `gpt-image-2` 生成，原始提示要求深墨绿手工和纸、轻微矿物色云和稀疏旧金纤维、低对比、无物体/文字/符号/边框/水印；生成后本地缩放压缩，运行时不访问生成接口。
- 事件素材 `assets/koi-event-petals.webp`、`assets/koi-event-dragonfly.webp`、`assets/koi-event-frog.webp`、`assets/koi-event-firefly.webp`、`assets/koi-event-splash.webp` 使用 GPT Image Proxy 的 `gpt-image-2` 分别生成。原图要求俯视、日式庭院绘本轻写实、纯绿背景且无文字/边框/水印；生成后执行透明抠图、去绿边、裁切与 WebP 压缩，五张合计约 225 KB。运行时只读取本地文件；素材尚未解码时保留原 Canvas 小景作为当帧兜底，不影响事件生命周期。
- 节气素材 `assets/koi-season-autumn-leaf.webp` 与 `assets/koi-season-winter-mist.webp` 也使用 GPT Image Proxy 的 `gpt-image-2` 生成；春季直接复用花瓣素材，夏季直接复用萤火虫素材。红叶和薄雾原图分别要求俯视单片红枫叶、透明冬日雾带、纯绿背景和无文字水印，随后本地抠图、去绿边、裁切并压缩为 22.7 KB 与 30.6 KB WebP。季节绘制限制为春 8、夏 7、秋 9、冬 2 个实例，减少动态效果时为 4、4、4、1 个。

### 玩水：正弦位移与双线性采样

- 以点击位置为中心，`d` 为像素到中心的距离，`t` 为经过的动画时间，令 `q = 74t - d`。只有 `0 < q < 72` 的移动波包产生位移；中心及波包外不处理。
- 位移采用 `h(d,t) = A(d,t) × sin(2πq / 22)`。振幅由初始强度、`exp(-0.7t)` 时间衰减、`1/(1+0.006d)` 距离衰减、寿命淡出和 `sin²(πq/72)` 平滑包络共同决定，避免波前硬切边。
- 将位移沿径向转换成浮点采样坐标。只对邻接像素索引用 `floor`，保留坐标的小数部分；用周围四个像素按横纵小数权重做双线性插值，不把采样位置提前取整。
- 从当前背景、锦鲤及饲料组成的未折射帧取样。多处点击的位移先相加，再统一采样一次；不反复扭曲已经变形的结果，避免累积拖影。利用正弦项斜率近似添加少量方向性明暗，变化限幅。
- 内核为 `assets/koi-pond-refraction.js`，在主脚本之前本地加载，随现有 `assets/*` 打包。不依赖 WebGL、网络、第三方库或新线程。
- 只截取活动波纹包围区域，以 CSS 像素处理，并裁切到中央水域；波包外输出透明像素、保留原图。径向三角函数先建短表，再按距离插值，避免逐像素重复计算三角函数。闲置、隐藏窗口时不进行这项折射计算。
- 投喂和玩水共用 500 毫秒互动冷却，投喂、进食和玩水合计最多保留 3 个活动折射波。鼠标、键盘以及禅模式使用同一入口，切换模式不重置冷却。超频、波纹满额或饲料满额的点击直接忽略，不排队、不新增波纹或饲料、不反复刷新提示；波纹消退后恢复互动。鱼吃食不受特效额度影响，满额时仅省略新增进食波纹。
- 这是二维画面折射近似，不是完整流体求解。限制降低连续点击的 CPU 开销，但不保证所有硬件的帧率；冒烟脚本验证密集点击、活动波纹上限和到期恢复，并记录内核耗时分位数和 3 个重叠波纹的单次耗时，不将其表述为整窗帧率。

专项验证：

```powershell
node node_modules/vitest/vitest.mjs run tests/koi-pond-refraction.spec.mjs tests/koi-pond.spec.ts
node scripts/smoke-koi-pond.mjs
```

内核测试覆盖四像素插值、径向传播、能量衰减、寿命结束、画面边缘、多波叠加和减少动态强度；Electron 冒烟确认实际画面像素被改变、处理局限于点击附近，并输出日夜截图、连续帧及 `refraction-timing.json`。

### 日夜美术还原边界

- 日间保留碧绿水色、叶影、水面光纹与日式庭院；夜间保留月光倒影、深蓝水色与暖灯。分别使用两张原稿，不用整体变暗替代夜景。
- 右侧面板位置、墨绿色底、细金线花角、荷花冠饰、左上朱印标题与底部双按钮按设计稿布局重建。保留真实鱼名、等级和成长计数，不烘焙设计稿中的示例数值。
- 原稿中的 UI 已覆盖一部分景物。清理时用邻近庭院纹理与无缝融合补齐这些区域；这部分是重建而非原始隐藏图层，不承诺像素级一致。UI 字体使用本机宋体／微软雅黑，字形会与设计稿中的绘制文字有差异。
- 原稿的静态花瓣、荷花、灯笼属于背景装饰；可投喂的锦鲤仍是存档中的真实鱼群。游动和投喂限制在中央水域，避免锦鲤游上屋顶和岸边。
- 鱼塘随主窗口内容区域调整大小；背景按等比铺满裁切而非拉伸，小窗口保留可滚动档案及全部操作。右上保留时段与禅模式入口，右下保留统一悬浮球，左侧执行列表按需显示。
- `assets/koi-pond-day.webp`、`assets/koi-pond-night.webp`、`assets/koi-pond-lotus.svg`、`assets/koi-pond-frame.svg` 都随现有 `assets/*` 打包规则进入安装包。

美术提取脚本只在重新处理设计稿时使用，需要本地 Python、Pillow、NumPy、OpenCV；普通启动及构建不需要这些 Python 库：

```powershell
python scripts/prepare-koi-art.py DAY_DESIGN.png NIGHT_DESIGN.png assets
```
