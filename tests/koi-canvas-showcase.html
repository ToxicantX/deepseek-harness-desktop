锦鲤全阶形态演化全景 (Stage 0 ~ Stage 10) Canvas 渲染验证

基于锦鲤池实际渲染引擎（原汁原味 koi-pond.js Canvas 2D Path 与鱼身着色器），展示全阶段身体尺寸、尾鳍延伸、胸鳍摆幅以及金色鱼鳞变化

核心演化机制与肉眼辨识分析

锦鲤池的演化档位由 stage = min(10, floor(level / 100)) 决定：

  • 0~99级（第1阶）与 100~199级（第2阶）： 基础体型仅增加约 16.7%（18px → 21px），尾鳍后延 +1.5%，胸鳍摆幅 +0.9px，且此时尚未达到鱼鳞生成条件，因此 100 级刚突破时肉眼感知较平缓。
  • 200级起（第3阶及以上）： 触发关键分水岭！正式激活 9 道同心金色背鳞（arc），背部开始具有层叠光泽。
  • 500级（第6阶）： 达到性成熟标志（可触发伴侣孕育），鱼身尺寸达到 33px（初始的 1.83 倍）。
  • 1000级（第11阶满阶）： 鱼身尺寸达 48px（初始的 2.67 倍），尾鳍与胸鳍舒展至最大尺寸，威严巡游。
